A make.fun entry for [One-Line Slogan for a Solana Wallet Agent](https://make.fun/bounty/u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e).

`main.ts` (Node 22, stdlib only) writes one slogan — a single line of at most 20 words — to `/output/entry.txt`. No network, no assets, no randomness. The program validates the slogan against the gate (1–140 characters, one line, ≤ 20 words, names the Solana wallet) before writing, and writes exactly the slogan bytes, no trailing newline.

> Your Solana wallet just grew a brain: ask once, and it handles the rest.

14 words, 72 characters. The fresh image is a wallet that "grew a brain"; the promise is plain: ask once, and the agent handles the rest.

Run it with:

```sh
node main.ts
```
